# 질문 강도 측정기 (Prompt Helper)

비밀번호를 만들 때 약함·보통·강함이 보이는 것처럼, AI에게 보내는 질문도 입력하는 순간 강도를 보여주는 도구입니다.

## 기능
- 질문을 입력하면 **약함 / 보통 / 강함**을 실시간으로 표시
- 강한 질문의 5가지 재료: **목적, 상황, 형식, 조건, 예시**
  - 0~1개: 약함 · 2~3개: 보통 · 4~5개: 강함
  - 질문 길이는 점수에 들어가지 않음
- 빠진 재료를 채우는 힌트 제공
- 전화번호, 이메일, 학교 이름, 주소 같은 개인정보가 들어가면 경고

## 실행 방법
`index.html` 파일을 브라우저로 열면 됩니다. 설치나 인터넷 연결이 필요 없습니다(글꼴만 온라인일 때 적용).
